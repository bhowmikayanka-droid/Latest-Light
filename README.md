# Lumina Flow

I want you to act as a UI/UX designer specializing in neumorphism and glassmorphism. Design a responsive web interface with a fluent slider to control light sensitivity, ensuring real-time bidirectional communication with an Arduino via WebSocket. The slider should dynamically reflect PWM data from the Arduino with zero latency. I want the UI like the image given to you
